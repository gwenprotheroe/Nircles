Nircles

Nircles is a tool for visualising folder structures using nested circles. It provides an alternative to traditional file explorers, allowing users to explore their file systems in a more intuitive and visually appealing way.

Created by Gwen Protheroe 2026.

Guide

This is a demonstration of alternative folder visualisation techniques. Other examples include branching trees, tree maps, and sunburst diagrams. These nested circles can be used to represent any arbitrarily complex hierarchy structure.

  • Larger circles or nested circles represent folders or directories.
  • Smaller, innermost circles represent individual files.

Created by Gwen Protheroe 2025.
