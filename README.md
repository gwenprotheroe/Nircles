<b>Nircles</b> is a folder visualisation and navigation tool.

It turns folders inside out, allowing you to see everything simultaneously. It can be overwhelming at first, and it absolutely is for poorly organised or overwhelming projects. 
It will enable you to find your <b>biggest</b> files, your <b>oldest</b> files, and <b>duplicate</b> files.
